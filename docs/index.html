Installation Guide

Choose your preferred method to get started

One-Command Installation (Recommended)

1

Install Termux

Download and install Termux from F-Droid (NOT Play Store version). The Play Store version is outdated and doesn't work properly.

2

Run the Installer

Open Termux and paste this command:

curl -L https://raw.githubusercontent.com/1ARCH-USER1/VentoyAndroid/main/install-termux.sh | bash
3

Create Your Ventoy Drive

Connect USB via OTG and run:

ventoy-termux.sh create

Manual Installation

1

Update Packages

pkg update && pkg upgrade -y
2

Install Dependencies

pkg install -y curl tar parted exfat-utils
3

Setup Storage

termux-setup-storage

Grant storage permission when prompted

4

Download Script

curl -L -o ventoy-termux.sh https://raw.githubusercontent.com/1ARCH-USER1/VentoyAndroid/main/ventoy-termux.sh
chmod +x ventoy-termux.sh
5

Run Ventoy Creator

./ventoy-termux.sh create

Android App Installation

1

Prerequisites

You need Android Studio or Gradle installed on your computer to build from source.

2

Clone Repository

git clone https://github.com/1ARCH-USER1/VentoyAndroid.git
cd VentoyAndroid
3

Build APK

export JAVA_HOME=/path/to/jdk-17
export ANDROID_HOME=/path/to/android-sdk
./gradlew assembleDebug
4

Install to Device

adb install app/build/outputs/apk/debug/app-debug.apk

Critical Warning

ALL DATA ON THE SELECTED USB DRIVE WILL BE ERASED!

This operation CANNOT BE UNDONE. Creating a Ventoy drive involves complete reformatting of the USB drive.

Always double-check you are selecting the correct drive before proceeding. The script requires typing "YES" to confirm.
